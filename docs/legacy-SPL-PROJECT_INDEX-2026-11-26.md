## Archive rule

- `99 Archive` contains retained legacy locations and earlier versions that are not current working roots.
- Archived content must not be treated as the current project record unless the project handover explicitly cites it.
- The dated legacy-location archive includes a checksum/deduplication report so old iCloud, Desktop and Documents material can be traced without restoring parallel working folders.

## Standard Context Pack

Each project should contain:

- `PROJECT_CONTEXT.md` — background, scope, status and working approach.
- `DECISION_REGISTER.md` — confirmed decisions and their basis.
- `DOCUMENT_REGISTER.md` — governing and working documents.
- `OPEN_ACTIONS.md` — pending work, owners and status.
- `AGENTS.md` — standing instructions for Codex within that project folder.

Update the project-level files when a material decision, document revision or action status changes.
