# Electrical audit drawings

Use the project audit method, current report and agreed engineering decisions as the basis. Confirm the site, circuit limits, authorized output and source revision. For a review request, report gaps in chat before editing. Where the owner requests a compact four-sheet A3 set, use these pairs.

| Sheet | Include |
|---|---|
| 1. Phase circuit | Show voltage levels, sources, winding connections, cable sizes, breaker tags and selected settings. Mark each fault between identifiable endpoints. For each source, name the detecting element and the device or inverter response that ends its contribution. |
| 2. Phase assessment | Reuse the fault labels. Show formula, substitution, units, result and decision. Check capacity, high-current duty and heating, weakest-source pickup at the actual CT or breaker, tolerances and intermediate clearing times. Refer currents to the correct winding. Compare upstream and downstream curves where coordination matters. |
| 3. Earth-fault circuit | Mark faulted phases and metalwork, return paths, sensors, relay inputs and trip destinations. Draw trip lines to breaker symbols. Show alarms and their recipients. Distinguish measured connections from assumed paths and proposed additions. Put key proof checks beside each device. |
| 4. Earth-fault assessment | Reuse the earth-fault labels. Separate first-fault detection, second-fault disconnection, touch voltage and conductor energy. Identify the design inputs, test method, acceptance criterion and result to record for each decision. |

For a two-source circuit, trace the current before and after the first interruption. Identify the opened path, any surviving return loop, the sources still able to feed it and the event that ends the last contribution. Check credible alternative breaker opening orders where the outcome changes. Use synchronized timing or applicable manufacturer evidence. Calculate the integral of squared total current in each conductor over all intervals. Credit inverter cessation on loss of reference only where the switching state actually removes that reference.

Separate a relay injection test from proof that the minimum fault reaches pickup. Specify approved CT/VT ratios, pickup and delay, fault-time trip supply, breaker interruption, and latching or reset where applicable. For primary failure, identify the backup detector, breaker, source removal time and withstand. State who must finish any outstanding design before commissioning.

Before delivery, follow every fault on the rendered drawing through its calculation, trip or alarm, and site check. Check the intended print size, text, symbols, junctions and trip arrows. Verify matching fault labels on the PDF and editable drawing. Identify the checks actually performed on the CAD file. Preserve prior revisions and record the current outputs in the site index.
