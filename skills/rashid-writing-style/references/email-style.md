# Email Style Notes

Use brief, simple, non-native-speaker-friendly English.

For internal emails, write like a manager sending a practical note to the team:

- Short subject.
- Simple opening.
- Few bullets only.
- No unnecessary politeness layers.
- No long justification.
- No repeated report facts unless needed to identify the issue.

When reviewing a technical document, include only the points that are not clear from the document or where the model/design basis must be confirmed.
